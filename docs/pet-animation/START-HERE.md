## 通用生成方法

首批 idle/search/pat 已完成。以下保留通用方法；本轮按待机包的文件名逐段生成，不必重做先前三段。

1. 进入可灵的图生视频或首尾关键帧入口，选你账号里支持该模式的模型。首批三段保持同一模型，不混用不同版本的风格。记录界面实际显示的模型名。
2. 首帧上传 `reference/tuntun-start-end.png`，尾帧也上传这一张。若当前模式没有尾帧入口，先只用首帧，提示词仍要求回到原姿势；回来后另验循环。无需上传 SVG、其他概念图或一张拼满动作的分镜图。
3. 建议起步参数：16:9、10 秒、720p 试片。选择单镜头，摄像机固定；若有智能多镜头、自动运镜、音画同步等选项，关闭这些选项。稳定后需要更清楚的边缘再用 1080p，不必先做 4K。
4. 打开对应 `.txt`，整段复制到提示词框。每份已经包含角色约束和时间轴，不用另外拼前缀。优先让模型按正面动作描述执行；不要额外叠加几百字的禁用词。
5. 下载原始 MP4，不经过聊天软件压缩。每次生成都保留新版本，按 `idle_take01.mp4`、`search_take01.mp4`、`pat_take01.mp4` 命名；重做递增 take02，避免覆盖。
6. 把视频与填写后的生成记录放到项目的 `data/pet-animation/incoming/`，或直接发回视频文件。不要放进网站静态资源目录，绿幕源片暂不作为网页资源。

可灵界面与账号开放能力可能不同。官方[首尾帧指南](https://kling.ai/quickstart/ai-video-start-end-frames)说明了双图约束；[当前模型使用指南](https://kling.ai/quickstart/kling-4-model-user-guide)强调以实际界面为准、用清晰的动作和时间顺序描述。以上是本站制作参数建议，不代表已替你提交生成或消耗可灵额度。

## 每段先看这些

- **同一只囤囤**：头身比例、毛色、耳朵、脸型和资料夹标签保持一致。两只爪子、三张卡片，不能时多时少。
- **干净背景**：绿色均匀，角色没有被绿光染色；没有地板、投影、字幕或场景切换。导出使用平台提供的合法原文件，不把去水印当制作环节。
- **空间稳定**：镜头不移动，角色不变大，耳朵和卡片不碰画边；原地跳跃落回同一点。
- **衔接自然**：结束时恢复参考姿势，比较首尾的脸、脚底和夹面；同一张首尾图仍可能出现最后一帧突然跳回，需要检查。
- **动作可读**：先看整个动作，再缩小到网站的约 120px / 78px，确认依然能认出在干什么。大量细小手指动作通常不适合。

如果失败，只修改一个问题再生成。例如“把卡片全部抽出”改成“只拨动现有卡片的上沿”；角色变脸时保持同一参考图和模型，把动作缩小。不把失真片继续用于后续视频的首帧。

## 视频回来以后

我会逐段检查、选 take，处理绿幕、绿色溢色和透明边缘，统一脚底与缩放，再输出网页素材。需要保留完整原片，方便重新抠像；图片文件伪装成透明底、普通 MP4 都不等于带透明通道。

当前三段已转换为 512×512、24fps VP9-alpha WebM，并保留原 SVG/CSS 回退。不要求你在可灵里输出透明视频。现阶段按用户要求保留约 10 秒全长直接使用；idle/search 循环、pat 单次，后续再处理接缝和过长的收势。

透明处理、播放器和 Edge 本机检查已完成，详情及重建方式见 [动画制作与接入](../pet-animation-production.md)。服务器尚未部署，Chrome/Safari 与真实移动设备待验证。
