## 防止再次发生的改动

- 补提取按来源独立校验，只重试失败项一次；仍无有效结果时显示待核对。入库使用每条来源的独立事务，坏条目不回滚同批正常记录。
- 共享检索补齐已确认的中英文机构名对应；具体模型别名由本轮人工核对保存。近似名称仍只用于召回。
- 新闻联合提取和补提取 prompt 区分框架、模型、未来计划、分辨率升级与实际开放；字段验证拒绝把明确的未来权重计划标成已开放。
- 首次发布与后续权重/API 开放使用不同事件阶段。运行 prompt 唯一来源仍为 `insight_agent.py::SYSTEM_PROMPT`、`model_discovery.py::PROMPT`，未另复制运行正文。
- 新增只读 `python -m backend.maintenance`：检查 SQLite 完整性、声明与软关联、新闻来源、事实逐字引用。离线合并函数只接受已经核实的两个 ID，不自行模糊合并。
- Compose 明确传递 `MODEL_AUTO_REVIEW_ENABLED`，默认 false；普通收录不恢复旧模型周期研究。
