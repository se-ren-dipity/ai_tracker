# 模型库列表展示

更新日期：2026-10-30。状态：v2 最近更新排序与隐藏管理入口已实现、本机已验证；15:42（北京时间）服务器部署 `0abb894` 并通过接口验收。

## 目标与当前设计

已确认要求：模型库分页显示；列表长描述省略，详情显示全文；模型行高基本一致。实现默认值：每页 20 条、描述最多两行，无待确认事项。

2026-10-30 追加要求：模型审核交给智能体，普通页面隐藏管理入口。自动审核设计见[模型自动审核方案](autonomous-model-review.md)，本轮仅隐藏页面入口，完整自动审核闭环尚未接通。

- 复用 `/api/models` 的 `page`、`page_size`、`total`，不再一次请求 200 条。上下两处翻页提供首页、上一页、下一页、末页及当前页数；不足两页时隐藏翻页按钮。
- 筛选或点击排序表头后回第一页；进入模型详情再返回保留页码和筛选。翻页滚回页面顶部；列表总数变化导致页码越界时返回最后有效页。
- 列表描述用 CSS 两行省略，保留两行高度。名称保持单行，机构与许可最多两行；固定列宽，窄屏可在表格内横向滚动，翻页控件留在表格外。
- 详情仍展示完整 `notes`，不截断接口数据或修改数据库。点击模型名称进入详情，长名称可悬停查看。
- 同排序值使用模型 ID 作为第二排序键；快速更改查询时只渲染最新请求。失败显示重试入口，不显示旧分页。
- 默认按 `updated_at` 最近收录/更新降序，未知日期排后；筛选区新增排序选择，仍可选择发布日期或点击表头。选择框与表头同步，切换后回第一页。没有发布日期的新模型也能被发现，不改写其发布日期。
- 移除模型库“模型审核”和页脚“管理员入口”；公开原文档案不显示管理导航。已有受鉴权保护的直达页面与 API 保留，认证及 CSRF 不变。

## 范围与验收

涉及前端 `index.html` 和后端模型列表排序；无数据库迁移、Agent 提示词、付费调用或权限调整。列表与详情仍使用现有只读接口。

本机自动验证：5 项前端分页回归、3 项前端鉴权/脚本检查、3 项后端分页/排序回归及 1 项静态资源缓存回归全部通过。覆盖分页边界、筛选/排序归位、空结果、请求失败及乱序响应、同排序值跨页无重复、筛选总数和完整描述保留。

本机 Edge 验收（Chrome 控制扩展未连接）：1194 条数据，每页 20 条，共 60 页，末页 14 条；首末页按钮正确禁用。第一页、末页及 Qwen 筛选结果的模型行高均约 81px，描述显示高度为 36px，两行截断。详情全文与列表原始描述一致、无裁切；返回保留第二页。末页搜索 Qwen 后显示 128 条、回第 1 / 7 页。未对服务器或移动设备做实机验收。

v2 本机验收：修复后的服务器备份副本共 1204 条、61 页。默认首页同时可见 ZwZ2 三个尺寸、Mistral Large 4 和 Brush；发布日期选项可切换后再切回。Edge 确认模型列表及原文档案无公开管理入口。16 项相关前端测试通过，覆盖选择框与表头排序同步、翻页和原有鉴权；后端分页测试确认默认按更新排序且空发布日期仍为空。此验证未修改线上数据。

服务器验收：web 与 collector 更新并 healthy，定向补录后共 1204 个模型；容器内 HTTP 检查确认默认前 20 条包含五个目标，五个详情可读，页面源码不含公开管理入口，匿名访问管理 API 仍返回 401。视觉验收使用上述本机 Edge 结果，未新增服务器浏览器或移动设备验收。

部署：同步前后端文件，重启 web 服务并刷新页面；其他 worker 无需重启。回退对应页面与列表路由即可，不需回滚数据。
